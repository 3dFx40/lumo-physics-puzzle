# LUMO 1.0.0

משחק פאזל פיזיקלי בעברית לטלפון Android ולדפדפן, עם 100 שלבים בעשרה עולמות. השלבים משלבים חבלים ותנופה, גשרים מסתובבים, מעגלי מתגים, מחסומים מתחלפים, קפיצים, רוח, מגנטים, שערים, כבידה ובית נע.

כולל שלושה כוכבים לפי הגעה, מספר פעולות ואיסוף ניצוצות; שמירת התקדמות; בחירת שלבים; Restart ומעבר לשלב הבא; רמזים; צלילים; משוב במגע והעדפות. כל הנכסים נשמרים מקומית והמשחק פועל ללא רשת.

## קבצים

- `LUMO-Android.apk`: APK חתום במפתח הפיתוח של Android, להתקנה ישירה. הוא הותקן ונפתח במכשיר Samsung Galaxy A73. הפצה בחנות מצריכה מפתח Release בבעלות המפתח ובניית AAB.
- `LUMO-Web.zip`: תוצר אתר מלא. יש לפרוס את הקבצים בשרת סטטי עם HTTPS כדי להשתמש בהתקנה כ־PWA ובעבודה ללא רשת.

## אימות

- פתרונות פיזיקליים של שלושה כוכבים עברו בכל 100 השלבים.
- אותן מאה תוצאות נבדקו בתוך Chromium.
- נבדקו לחיצות מגע על חבלים, סיבוב, מתגים, קפיצים, רוח, מגנטים, שערים וכבידה.
- נבדקו מעבר שלב, Restart, בחירת עשרת העולמות, רמזים והעדפות, ושמירה אחרי טעינה מחדש.
- גרסת ההפצה נטענה ללא חיבור, אפשרה פתרון במגע, שמירה ומעבר לשלב הבא.
- המראה נבדק במסך נייד, במסך מחשב ובצילום ממכשיר Android פיזי.

בדיקות משחק עם קבוצות גיל עדיין נדרשות כדי למדוד את רמת האתגר והלמידה. פתרונות ייחוס מאמתים פתירות, ואינם מוכיחים איזון קושי לכל שחקן.
